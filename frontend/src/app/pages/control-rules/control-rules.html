Types de règles disponibles

monetization_on Montant

Définit un seuil de montant. Les transactions dépassant ce seuil seront signalées comme anomalies selon la période référence.

history_toggle_off Fréquence

Détecte les comportements anormaux basés sur le nombre de transactions. Utile pour identifier les activités inhabituelles.

public Pays à Risque

Surveille les transactions impliquant des pays à risque définis. Permet de bloquer ou surveiller les transactions sensibles.
